# wenchun-blog

Personal website and blog built on Blogger.

🌐 Live Demo: <https://wenchunlife.blogspot.com/>

## About

This project documents the design and development of
my personal website, including Blogger theme customization,
frontend components, widgets, and design decisions.

## Original Theme

This project is based on the free Blogger theme **Renique** by **OddThemes**.

- **Theme:** Renique Blogger Template
- **Author:** OddThemes
- **Source:** <https://gooyaabitemplates.com/renique-blogger-template/>
- **Author Website:** <https://oddthemes.com/>
- **Documentation:** <https://blog.oddthemes.com/renique-feminine-blogger-template-documentation/>
- **Platform:** Blogger
- **License:** Refer to the original theme's license and usage terms.

The original theme is preserved as the baseline for this project.
All subsequent customizations documented in this repository are my own modifications.
